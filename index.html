WEB / APPLICATION PROJECT · 01

Complaint Management & Resolution Tracking System

A simple application that helps record complaints, monitor their status, and keep the resolution process organized.

Project overview

The system stores complaint information and gives each complaint an ID, making it easier to find a complaint and follow its progress from submission to resolution.

Key features

  • Add and record a complaint
  • Generate a unique complaint ID
  • View submitted complaints
  • Update complaint status
  • Track Pending and Resolved complaints

How it works

Users choose an option from the menu to add a complaint, view existing records, update a status, or exit the application.

Technologies

Java ArrayList Scanner OOP basics
